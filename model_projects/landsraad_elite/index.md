# Landsraad Elite

Model project for the Landsraad Elite and related Landsraad guard variants.

- [SPEC.md](SPEC.md) — project layout, modeling and export notes, game-data changes,
  model variants, and remaining in-game checks.
- `01_input/` — source sculpt and reference material.
- `02_progress_photos/` — progress screenshots.
- `03_blender/` — staged Blender projects and backups.
- `04_textures/` — baked texture maps.
- `05_fbx_export/` — exported FBX files for conversion.
- `06_game_ready/` — converted models and related game-ready assets.
- `07_data_cdb/` — CDB changes and snapshots.
- `08_scripts/` — scripts and intermediate files used in the workflow.

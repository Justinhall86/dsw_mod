# Archived Thorvald projects (not used in the game)

Moved here 2026-11-01 after checking which models the live Thorvald faction uses (`mod_files/data.cdb`: `Th_Trooper`, `Th_Soldier`,
`Th_Special`, `Th_Elite`, `Th_Frigate`, `Th_Ship`). None of these three feeds a live model. They are kept, not deleted, so nothing is lost.
Safe to delete this whole folder once you are sure you will not want any of it.

| Folder | What it was | Replaced by |
|---|---|---|
| `thorvald_fighter` | Renegade frigate copper recolour (v1-v3), keel fin removed, plus a rejected hand-built top kit | `thorvald_frigate` |
| `thorvald_interceptor` | Wraith-drum kitbash on four hulls (A-D), never exported | `thorvald_frigate` |
| `thorvald_vehicles` | Early vehicle explorations (drone kit, carryall, claw hauler, Kraken/Banshee parts) | `thorvald_ship`, `thorvald_frigate` |

The frigate's concept sheet was copied out to `thorvald_frigate/01_input/reference_sheet_v2_frigate_jets.png` before archiving.

# House Ginaz: design bible

A custom House of duellists for Dune: Spice Wars. Four units are built and in the game data (Captain, Swordmaster, Neophyte, Master); everything else here
is design, art direction and planning, organised so each question has one file to answer it.

Source images are in [images/](images/). Most concept images were generated by an image model: they are **reference, not spec**
(text is garbled, emblems vary, faces repeat). Where they disagree, [art_direction.md](art_direction.md) states the canon.

## Status at a glance (2026-10-25)
- In the game data (a `Ginaz` faction cloned from Atreides, installed, **not yet launched**): **Ginaz Captain** (`G_Elite`, squad 5, one squad at the start), **Ginaz Swordmaster** (`G_Trooper`, uses the Captain's model),
  **Ginaz Neophyte** and **Master of Ginaz**. The Captain was confirmed working in game on 2026-10-24 (then as the Atreides Warden); the Atreides Warden is vanilla again. Details: [unit_specs.md](unit_specs.md).
- Designed, not built: Scout, Throwers, Elite Swordmaster; the real faction bonuses (the data still has Atreides ones); Grandmasters and Councilors beyond the placeholders.
- Tooling: the whole unit-building process is saved as the `dsw-new-unit` skill (`.claude/skills/dsw-new-unit/`).

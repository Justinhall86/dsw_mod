# House Ginaz: design bible

A custom House of duellists for Dune: Spice Wars. One unit is already in the game (the Ginaz Captain). Everything else here
is design, art direction and planning, organised so each question has one file to answer it.

| Read this | When you want to know |

| [identity_and_lore.md](identity_and_lore.md) | who they are: symbols, tone, vocabulary, how the House plays and what it is NOT |
| [faction_design.md](faction_design.md) | the faction bonuses (both concept versions), a reconciled proposal, hegemony milestones, balance questions |
| [leaders_and_councilors.md](leaders_and_councilors.md) | Grandmasters (leader choice) and Councilors, abilities, synergies, proposed fixes for the unfinished ones |

Source images are in [images/](images/). Most concept images were generated by an image model: they are **reference, not spec**
(text is garbled, emblems vary, faces repeat). Where they disagree, [art_direction.md](art_direction.md) states the canon.

## Status at a glance (2026-10-24)
- In the game: **Ginaz Captain** (over the Atreides Warden slot, squad 5, one squad spawns at game start). Confirmed working.
- Designed, not built: Scout, Throwers, Elite Swordmaster, Master of Ginaz; the faction bonuses; four Grandmasters; four Councilors.
- Tooling: the whole unit-building process is saved as the `dsw-new-unit` skill (`.claude/skills/dsw-new-unit/`).
